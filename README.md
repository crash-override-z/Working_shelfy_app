# shelfy-app
Shelfy App
**#Shelfie** is a community-driven sushi inventory app built for Fujiya, a Victoria-based Japanese grocery store. The core problem it solves: customers drive across town only to find their favourite sushi is already sold out.

**#Phase 1 — The Request Feature** Customers open the app and request which sushi items they wish were in stock. Each request is timestamped and stored in a database. This gives the store real demand data before stocking decisions are made.

**#Phase 2 — Smart Inventory + Rewards**

- A forecasting engine parses request data to predict what to order (e.g. 32 salmon rolls for Saturday)
- Vendors receive data-driven order suggestions, reducing overstock and waste
- Customers earn points for contributing updates or photos
- A pre-pay + pickup option for $1.50 is planned

**#Tech Stack (planned)**

- C# backend, SQL database, Azure cloud
- Lovable + Figma for UI prototyping
- Mobile-first wireframes already designed

**The "Why"** It started as a group chat ("is there sushi?"), evolved through a spreadsheet and scrappy prototype, and is now being built through COMIT. The goal is to cut wasted trips, reduce food waste, lower inventory costs, and increase Fujiya's revenue — all from a small, focused Victoria-based app.
